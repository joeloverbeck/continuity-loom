## Note for a future cycle

plausible — nothing here says they did not happen. What the trials establish is that the current
`SKILL.md` text does not *cause* them under fresh, blind, short-context conditions. If the lapse
recurs, the next cycle should treat context distance inside a long host run as the binding
constraint and build an instrument that can vary it, since a one-shot fresh executor demonstrably
cannot reproduce it.
